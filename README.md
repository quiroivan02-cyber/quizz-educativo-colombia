# ¿Quién quiere ser millonario?

A classroom quiz game for Mathematics and Colombian general knowledge. Choose a money or grade mode, answer 20 questions, and use the available lifelines.

## Requirements

- Node.js 18 or newer
- npm

## Run locally

```bash
git clone https://github.com/quiroivan02-cyber/quizz-educativo-colombia.git
cd quizz-educativo-colombia
npm install
npm start
```

The app opens at `http://localhost:3000`.

## Verify and build

```bash
npm test -- --watchAll=false
npm run build
```
